## DAY 27 
1. **Problem**: [**Number of occurrence**](https://www.geeksforgeeks.org/problems/number-of-occurrence2259/1)  
- **hint**: try to find the first occurrence of the element and the last occurrence of the element.
## DAY 28 
1. **Problem**: [**Sorted and Rotated Minimum**](https://www.geeksforgeeks.org/problems/minimum-element-in-a-sorted-and-rotated-array3611/1)  
- **hint**: the element from where the array is rotated is the minimum.
- **hint**: try to use binary search to find the minimum element.
- **hint**: if mid is less than the end element it means that the array is sorted from mid to end, then the minimum element lies in the left half of the array.
## DAY 29  
1. **Problem**: [**Search in Rotated Sorted Array**](https://www.geeksforgeeks.org/problems/search-in-a-rotated-array4618/1)  
- **hint**: just try to find the pivot from where the array is rotated because the array is sorted from start and pivot and from pivot to end.
## DAY 30  
1. **Problem**: [**Peak element**](https://www.geeksforgeeks.org/problems/peak-element/1)  
- **hint**: the given array is nearly sorted, so try to use binary search.
- **hint**: if the mid element is greater than its neighbours then it is a peak element.
- **hint**: if the `(mid + 1)` element is greater than mid then there is high probability that peak element lies in the right half of the array.
- **hint**: try to take care of edge cases seperately.

## DAY 31  
1. **Problem**: [**K-th element of two Arrays**](https://www.geeksforgeeks.org/problems/k-th-element-of-two-sorted-array1317/1)  
    - **hint**:  just take two pointer i and j for both array and compare them to find the current element of merged sorted array.
    - **hint**: just take and k variable which keep track the number of elements which are potential member of the merged sorted array.  


## DAY 32  
1. **Problem**: [**Aggressive Cows**](https://www.geeksforgeeks.org/problems/aggressive-cows/1)
    - **hint**: greedy place the first cow at the first stall and then try to place the next cow at the maximum possible distance.
    - **hint**: take a max distance says 'd' and check if you can place all cows at a distance of 'd' or not. if not then reduce the distance and try again.

## DAY 33  
1. **Problem**: [**Allocate Minimum Page**](https://www.geeksforgeeks.org/problems/allocate-minimum-number-of-pages0937/1)
    - **hint**: If you can allocate maximum n pages then try to minimize the n.
    - **hint**: n is not valid answer if before the allocation of books, students get exhausted because each book has to be allocated to a student.

## DAY 34
1. **Problem**: [**Kth Missing Positive Number in a Sorted Array**](https://www.geeksforgeeks.org/problems/kth-missing-positive-number-in-a-sorted-array/1)
    - **hint**: Search for the missing number in the array.
    - **hint**: Can you use sorted array to find number of missing till ith position.

## DAY 35
1. **Problem**: [**Spirally traversing a matrix**](https://www.geeksforgeeks.org/problems/spirally-traversing-a-matrix-1587115621/1)
    - **hint**: Take 4 pointers top, right, left, bottom and traverse the topmost row from left to right, then rightmost column from top to bottom, then bottommost row from right to left and then leftmost column from bottom to top.
    - **hint**: Now try to reduce the size of the matrix.

## DAY 36
1. **Problem**: [**Rotate by 90 degree**](https://www.geeksforgeeks.org/problems/rotate-by-90-degree-1587115621/1)
    - **hint**: Try to find transpose of the matrix, then observe the pattern of the matrix.
